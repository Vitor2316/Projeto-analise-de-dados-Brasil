## FEATURES BY CATEGORY

### 1. CORE ANALYSIS (Base - Version 3.0)

**Scripts:**

- `graficos_finais_v3_parte1.R` - R alternative (charts 1-5)

- Distributional analysis (percentiles)

### 2. ADVANCED STATISTICS (Version 3.5 Hard)

**Scripts:**
- `analise_estatistica_avancada.py`

**Features:**
- Linear regression (Unemployment → Wage)
- 95% confidence intervals
- P-values and significance tests
- Structural break analysis (pre/post-2021)
- Feature engineering (volatility, trends)
- Correlation matrix

**Outputs:**
- `analise_estatistica_avancada.csv`
- Statistical validation of hypotheses

### 3. FORECASTING & SIMULATION (Version 3.5 Hard)

**Scripts:**
- `previsao_2026_2030.py`
- `simulador_avancado.py`

**Features:**
- Multi-model forecasting (linear, recent, scenarios)
- Monte Carlo simulation (10,000 iterations)
- Sensitivity analysis (ceteris paribus)
- Stress testing (extreme scenarios)
- Scenario matrix (heatmaps)

**Outputs:**
- `previsoes_2026_2030.csv`
- `monte_carlo_10k.csv`
- `monte_carlo_resumo.csv`
- `stress_test_resultados.csv`
- Charts 11-14

### Quick Start (Core Analysis)
```bash
git clone https://github.com/Vitor2316/Projeto-analise-de-dados-Brasil.git
cd Projeto-analise-de-dados-Brasil
pip install -r requirements.txt
python scripts/gerar_graficos_v3.py
```
